Question:
The XXII Commonwealth Games 2022 were hosted by which city?

Candidate selected: C
Response-sheet keyed option: D
Correct option: C — Birmingham

Evidence summary:
The official Commonwealth Sport page identifies the event as Birmingham 2022 and lists Birmingham, England as the host location for the Games held from 28 July to 8 August 2022. Therefore option C is correct.

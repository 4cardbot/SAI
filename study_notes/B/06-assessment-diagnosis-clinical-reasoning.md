# B — Assessment, Diagnosis & Clinical Reasoning

## Examination sequence

Examine the athlete in this order:

1. Take the subjective history and screen for red flags.
2. Observe the athlete and assess a relevant functional task.
3. Palpate, measure active and passive range of motion, and test resisted movement.
4. Perform manual muscle, neurological and circulation checks.
5. Add special tests and a validated outcome measure.
6. Form a working diagnosis and differential diagnosis.
7. Make a plan and reassess the response.

### Four-part clinical note

**Subjective:** history, symptoms, mechanism, goals, 24-hour response.
**Objective:** measured findings and test conditions.
**Assessment:** interpretation, differential, irritability, impairments and functional meaning.
**Plan:** intervention, education, load, referral/escalation and review date.

## Diagnostic accuracy

```text
Sensitivity = true positives/(true positives + false negatives)
Specificity = true negatives/(true negatives + false positives)
Positive likelihood ratio = sensitivity/(1−specificity)
Negative likelihood ratio = (1−sensitivity)/specificity
```

Use a high-sensitivity test to help rule out when negative and a high-specificity test to help rule in when positive. Test accuracy varies by examiner, population, disease stage and reference standard.

## Common exam associations (not stand-alone diagnoses)

| Test | Common association |
| --- | --- |
| Lachman | Anterior cruciate ligament (ACL) integrity; often taught as a sensitive ACL test |
| Pivot shift | Rotational ACL instability; often taught as a more specific ACL test |
| McMurray/Thessaly | Meniscal involvement; interpret with history and other findings |
| Anterior ankle drawer | Anterior talofibular ligament (ATFL)/lateral ankle instability |
| Talar tilt | Calcaneofibular ligament (CFL)/lateral ligament stress |
| Thompson/Simmonds | Achilles tendon rupture screen |
| Apprehension/relocation | Anterior shoulder instability |
| Neer/Hawkins-Kennedy | Shoulder pain/impingement provocation; not a single-tissue diagnosis |
| Speed/Yergason | Biceps-related provocation patterns |
| Flexion–abduction–external rotation (FABER) | Hip/sacroiliac-region provocation; location of symptoms matters |
| Straight-leg raise/slump | Neural mechanosensitivity/radicular pattern; structural differentiation matters |

## Manual muscle testing and range of motion

```text
0 no visible/palpable contraction
1 trace contraction
2 full range in gravity-eliminated position
3 full range against gravity
4 moderate resistance
5 normal/maximal resistance for the test position
```

End-feel: hard (bone), firm (capsule/muscle), soft (tissue approximation), empty (pain stops movement), or abnormal/springy depending on context. Document pain, quality, range, side and position.

## Outcome measures

| Domain | Examples |
| --- | --- |
| Pain | Numeric Pain Rating Scale / Visual Analogue Scale |
| Lower limb function | Lower Extremity Functional Scale; Knee injury and Osteoarthritis Outcome Score; International Knee Documentation Committee score |
| Upper limb | Disabilities of the Arm, Shoulder and Hand / QuickDASH |
| Tendon | Victorian Institute of Sport Assessment–Achilles / –Patellar |
| Psychological readiness | Anterior Cruciate Ligament–Return to Sport after Injury scale and similar sport-specific tools |

## Red flags and referral

Progressive neurological deficit, fracture/dislocation concern, vascular compromise, infection/systemic illness, unexplained night pain/weight loss, cauda-equina features, severe mechanism or deteriorating consciousness override routine exercise testing.

## Easy ways to remember it

- Examine in this order: **history, observation, function, nerves and circulation, then special tests**.
- **Rule out danger before naming the injured tissue.**
- For every test ask three simple questions: **What structure or movement is stressed? What is the best comparison or reference? How reliable is this test in this situation?**

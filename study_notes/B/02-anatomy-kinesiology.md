# B — Human Anatomy & Kinesiology

## Planes, axes and movement

| Plane | Axis | Typical movement |
| --- | --- | --- |
| Sagittal | Mediolateral | Flexion/extension |
| Frontal | Anteroposterior | Abduction/adduction |
| Transverse | Vertical/longitudinal | Rotation |

## Rotator-cuff and shoulder anchors

| Muscle | Action / nerve cue |
| --- | --- |
| Supraspinatus | Initiates abduction; suprascapular nerve |
| Infraspinatus | External rotation; suprascapular nerve |
| Teres minor | External rotation; axillary nerve |
| Subscapularis | Internal rotation; upper/lower subscapular nerves |
| Deltoid | Major abductor after initiation; axillary nerve |
| Serratus anterior | Scapular protraction/upward rotation; long thoracic nerve |
| Trapezius | Scapular elevation/retraction/upward rotation; spinal accessory nerve plus cervical contributions |

Mnemonic: rotator cuff **SITS** = Supraspinatus, Infraspinatus, Teres minor, Subscapularis.

## Lower-limb anchors

| Region | High-yield cue |
| --- | --- |
| Hip | Gluteus medius stabilises pelvis in single-leg stance; superior gluteal nerve |
| Knee | Quadriceps extends knee; femoral nerve. Hamstrings flex knee/extend hip; tibial division of sciatic nerve predominates |
| Ankle | Tibialis anterior dorsiflexes; deep fibular nerve. Gastrocnemius/soleus plantarflex; tibial nerve |
| Foot | Tibialis posterior supports the medial arch; tibial nerve. Fibularis longus everts and supports the transverse arch; superficial fibular nerve |

## Peripheral nerves and quick neurological screen

| Root/nerve level | Typical sensory or reflex cue |
| --- | --- |
| C5 | Lateral upper arm; biceps reflex contribution |
| C6 | Thumb/lateral forearm; brachioradialis contribution |
| C7 | Middle finger; triceps contribution |
| C8 | Little finger/medial hand |
| T1 | Medial forearm |
| L4 | Medial leg; patellar reflex contribution |
| L5 | Dorsum of foot/great toe; great-toe extension myotome |
| S1 | Lateral foot; Achilles reflex contribution |

Dermatomes, myotomes and reflexes are screening patterns, not isolated proof of a lesion. Compare sides and integrate pain, strength, sensation and neural tension.

## Arthrokinematics

```text
Convex-on-concave: roll and glide opposite directions
Concave-on-convex: roll and glide same direction
```

Open kinetic chain: distal segment free; closed kinetic chain: distal segment fixed/loaded and multiple joints share demand. Neither is universally “safe” or “unsafe”; choose by stage, tissue, load and task.

## Kinesiology reasoning

```text
Joint position → muscle line of pull → moment arm → torque → movement/control
```

## Memory tactics

- **SITS** for the cuff; **F-A-T-D** for a quick upper-limb nerve cue: Femoral = anterior thigh/knee extension, Axillary = deltoid, Tibial = plantarflexors, Deep fibular = dorsiflexors.
- Root ladder: **C5 shoulder, C6 thumb, C7 middle, C8 little; L4 knee, L5 great toe, S1 heel/lateral foot.**
- When asked about a muscle, answer in four parts: **action–position–nerve–task.**
